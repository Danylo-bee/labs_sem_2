Лабораторні роботи з дисципліни "Алгоритмізація та програмування (частина 2)"

Виконав:Грамолін Данило Олександрович(ІР-14)

Лабораторна робота №3 (Рівень 3 варіант 2)

Для заданого бінарного дерева перевірте, 
чи воно є збалансованим деревом. 
Бінарне дерево вважається збалансованим, 
якщо різниця у висоті його лівого 
та правого піддерев не перевищує 1 для будь-якого піддерева.
