Лабораторна робота №7 (Рівень 3 варіант 2)

Створити функцію на мові програмування Python, яка приймає дві стрічки: 
"haystack" (довільний текст) та "needle" (шукана стрічка). 
Програма повинна знайти  індекси всіх входжень стрічки "needle" в стрічці "haystack" 
та повернути цей індекс,  використовуючи  метод Кнутта-Морріса-Прата для пошуку підстрічки у стрічці
